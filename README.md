# Сайт бухгалтера — Оренбург (Astro)

Главная страница пересобрана на чистом Astro по дизайну «Бухгалтер Плюс»
(зелёный/тёмно-синий, шрифт Onest), с реальным контентом под личный бренд.
Свёрстана как дизайн-система — остальные страницы разворачиваются на тех же
компонентах и токенах.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:4321
npm run build    # прод-сборка в ./dist
npm run preview  # предпросмотр собранного
```

## Где что лежит

```
src/
├── data/site.ts          ← ВЕСЬ текст, цены, контакты, FAQ (правь здесь)
├── styles/global.css     ← токены дизайна (палитра, шрифт, радиусы)
├── layouts/Base.astro    ← SEO-мета, Open Graph, schema.org (Accountant)
├── components/           ← Header, Hero, Services, Niches, WhyOutsource,
│                            About, Process, Pricing, Faq, Cta, Contacts, Footer, Icon
└── pages/index.astro     ← сборка главной из компонентов
public/assets/            ← hero.jpg, services-flow.png
```

## ⚠️ Плейсхолдеры — заменить перед публикацией

Все помечены `__PLACEHOLDER__` в `src/data/site.ts` и в компонентах:

- **имя** бухгалтера (сейчас демо «Ирина Соколова»);
- **стаж** в годах;
- **телефон**, **e-mail**, **точный адрес**, время ответа;
- **фото** в блоке «Обо мне» (`src/components/About.astro`) — сейчас SVG-заглушка;
- **карта** в «Контактах» — подставить карту своей карточки Яндекс Бизнеса;
- **hero-фото** (`public/assets/hero.jpg`) — стоковое, стоит заменить на своё;
- **домен** в `astro.config.mjs` (нужен для sitemap, canonical, OG);
- **соцсети** (WhatsApp/Telegram) в футере.

- **Услуги** свёрстаны функциональной сеткой карточек-ссылок (а не

  отдельная SEO-страница, ссылки уже проставлены по `struktura-sayta.md`.

  макета (4 900 / 8 900).
